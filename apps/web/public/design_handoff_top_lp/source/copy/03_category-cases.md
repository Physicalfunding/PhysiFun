# カテゴリ + 事例カード プロンプト

## 既存実装の要点

- カテゴリタブ: すべて / 建築 / カフェ・飲食 / キャンプ場 / 農業 / イベント / スポーツ
- 事例カード: 画像 + タグ + タイトル + リーダー名 + Instagram + 統計（支援者数 / 時間）
- グリッド 1/2/3 列レスポンシブ
- ホバー時にカード持ち上がり
- 実装: `apps/web/src/components/top/CategorySection.tsx`

## 添付推奨

- `docs-repository/references/フィジファン_HPデザイン_追記.pdf` Page 2
- 既存実装のスクリーンショット

## このプロンプトを Claude Design に投入

---

カテゴリ別の事例紹介セクションをリファインしてください。

**狙い**:
訪問者が「自分のプロジェクトもこういう形でフィジファンに載せられるんだ」と具体的にイメージできるようにする。

**現状の構成**:
- カテゴリタブ（横並び 7 個）
- 「あなたの目的にあった事例がきっとみつかる！」吹き出し
- 事例カード一覧（3 列グリッド）

**改善したいポイント**:
1. カテゴリタブが多くて選びにくい → 視覚化（アイコン + 色分け）強化
2. 事例カードの情報密度を上げつつ、可読性を保つ
3. 「支援者 100 人 / 1000 時間」など数値の見せ方を魅力的に
4. カードクリック後の遷移を期待させる UI（「もっと見る」アクション）

**カード必須要素**:
- メイン画像
- タグ（最大 2 個）
- プロジェクトタイトル（2 行まで）
- リーダー名 + Instagram ハンドル（任意）
- 支援者数（人）
- 支援時間（時間）— ⭐ フィジファン独自指標、目立たせる

**改善案の方向性（3 案）**:
- **A: マガジン型** — 大判ヒーローカード 1 枚 + 小カード 4 枚で「特集記事」感
- **B: グリッド整列型** — 統一感重視、すべて同サイズ + ホバーで詳細プレビュー
- **C: タイムライン型** — 進行中・募集中・完了の進捗状態でグルーピング

**出力**:
- 3 案 + 各デスクトップ・モバイル
- カテゴリタブ部分も合わせて再設計
- ※ 事例データは Phase 1 段階ではモック（既存 6 件のサンプルあり）
