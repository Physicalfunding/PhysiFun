# リーダーの声 セクション プロンプト（新規）

## 背景

PDF 追記版 Page 3 に登場した「ご利用者の声」セクション。リアルな先行リーダーのストーリーで信頼感を高める。

## 添付推奨

- 追記 PDF Page 3 中央のインタビュー部分
- リーダー候補の現場写真（あれば）

## このプロンプトを Claude Design に投入

---

先行リーダーのインタビュー記事を載せる「リーダーの声」セクションを新規デザインしてください。

**狙い**:
- 抽象的なサービス説明だけでなく、**実在する人** の語りで信頼感を作る
- 訪問者が「自分も同じように使えるかも」と感じる

**カードの構成要素**:
- リーダー写真 or 現場の写真（左右どちらかに大きめ）
- 引用文タイトル: 例「行き届いたフィジファンの対応に感謝」
- 引用本文: 100〜200 文字程度
- リーダー名 + プロジェクト名 + Instagram ハンドル
- アバター（小さめ円形）+ プロジェクトサムネイル

**改善案の方向性（3 案）**:
- **A: 大判 1 枚 + 小カードカルーセル** — 1 件をフィーチャー + スワイプで他リーダーへ
- **B: 縦リスト型** — 2〜3 件を縦並び、写真を左右交互に配置（ジグザグレイアウト）
- **C: ポートレートグリッド** — 4〜6 件を顔写真メインのグリッドで、ホバーで引用展開

**Phase 1 用ダミーデータ**:
- リーダー名: Camperman / DIY Lavo / 株式会社 Hai-tacchi（PDF 参照）
- プロジェクト: キャンプ場運営 / 古民家リノベ / シャッター街復活

**必須要素**:
- 引用符（“ ”）の装飾を入れて「声」感を出す
- 写真は人物 + 現場の作業シーン
- リーダー情報の信頼性を担保する（実名 / SNS）
- セクション見出し: 「ご利用者の声」または「先行リーダーの声」

**出力**:
- 3 案 + 各デスクトップ・モバイル
- カルーセル / リスト / グリッドの操作 UI も含めて
