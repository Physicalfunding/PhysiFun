# Hero セクション プロンプト

## 既存実装の要点

- 上 70〜80vh: 背景動画フルスクリーン
- 下: 赤背景の説明エリア（キャッチ + 説明 + サービス名由来 + CTA）
- キャッチ: 「あなたの『好き』が、誰かの『助け』になる。最高のフィジファン体験を。」
- CTA: 「プロジェクトをつくってみる」→ `/apply`
- 実装: `apps/web/src/components/top/HeroSection.tsx`

## 添付推奨

- `docs-repository/references/フィジファン_HPデザイン_追記.pdf` Page 1
- 既存実装のスクリーンショット
- `apps/web/public/videos/hero.mp4`（or サムネイル）

## このプロンプトを Claude Design に投入

---

リーダー募集 LP のヒーローセクションをリファインしてください。

**現状の構成**:
- 上半分: 現場作業の動画背景（70vh）
- 下半分: 赤背景にキャッチコピー + サービス説明 + 由来 + CTA

**改善したいポイント**:
1. 動画と赤背景セクションが分断されて見える → もっと滑らかに繋げたい
2. 説明文が長く読み飛ばされやすい → 視線誘導を強化
3. CTA の存在感をもっと出す（ファーストビュー内に CTA を含める案も検討）
4. 「フィジカル + クラウドファンディング」の由来表記をもっと洗練

**必須要素**:
- メインキャッチ: 「あなたの『好き』が、誰かの『助け』になる。」
- サブキャッチ: 「最高のフィジファン体験を。」
- CTA: 「プロジェクトをつくってみる」（`/apply` へリンク）
- 動画 or 高品質ビジュアル
- ブランドカラー `#c62828` をどこかに必ず使う

**出力**:
- **3 案** 提示（A: 動画オーバーレイ型 / B: 縦分割型 / C: グラデーション統合型 などコンセプト違いで）
- 各案デスクトップ + モバイルの 2 バリエーション
- 各案 30 秒以内で「何を訴求したいか」を読み取れること
