# 循環図セクション プロンプト

## 既存実装の要点

- 赤背景（physifun-red）
- 左: 「あなたの得意なこと」中央 + 周囲アイコン（設計・農作業・料理・体験）
- 中央: フィジファンシンボル（白背景の角丸に黒シンボル）
- 右: 「実現したいこと」中央 + 周囲アイコン（古民家再生・畑づくり・イベント・キャンプ場）
- 下部: 「リターン」（モノ・コト・体験）
- 実装: `apps/web/src/components/top/CycleSection.tsx`

## このプロンプトを Claude Design に投入

---

「フィジカル ↔ ファンディング」のサービス構造を視覚化する循環図セクションをリファインしてください。

**伝えたい構造**:
1. **左**: ユーザーの「スキル・時間（フィジカル）」
2. **中央**: フィジファンが繋ぐ
3. **右**: リーダーの「実現したいこと（プロジェクト）」
4. **戻り**: サポーターが受け取る「リターン（モノ・コト・体験）」

**現状の課題**:
- 円形クラスター + 中央シンボル + 下部リターン の 4 ブロック構造が静止画的
- スキル → プロジェクト → リターン の **流れ** が伝わりにくい
- 絵文字アイコンの統一感が弱い（ライン or フラットアイコンに統一したい）

**改善案の方向性（3 案）**:
- **A: 矢印フロー型** — 左 → 中 → 右 → 下 → 左 の循環矢印を明示
- **B: 三角構造型** — リーダー / サポーター / フィジファン の三角形 + 各辺に動詞ラベル
- **C: ストーリーカード型** — 1 つのプロジェクトの流れを 3〜4 コマで展開

**必須要素**:
- 「あなたの得意なこと（スキル・時間）」「実現したいこと」「リターン（モノ・コト・体験）」の 3 概念
- フィジファンのロゴ or シンボルを中央に配置
- アイコンは統一感のあるライン or フラットスタイル

**出力**:
- 3 案（A/B/C）+ 各デスクトップ・モバイル
- 「30 秒で訪問者がフィジファンの仕組みを理解できる」を最優先
- 赤背景は維持、ただし白抜きパネルやグラデーションでリズムを作るのは可
