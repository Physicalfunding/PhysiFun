# サービスブリーフ（Claude Design へ投入）

## サービス名

**フィジファン（フィジカルファンディング）**

英表記: Physical Funding（Physical + Crowdfunding）

## 一行で言うと

お金ではなく、**スキルと時間**でプロジェクトを支援するマッチングプラットフォーム。

## ターゲット

### Phase 1（現在）: リーダー候補

- 古民家再生 / 米作り / DIY / カフェ復活 / キャンプ場運営 / 地域イベントなどの **現場プロジェクトを立ち上げたい個人・小規模団体**
- 30〜50 代中心、地方在住も多い
- クラウドファンディング（CAMPFIRE 等）の経験はある or 関心がある層
- 金銭支援だけでは届かない「現場で一緒に汗をかいてくれる人」を求めている

### Phase 2（将来）: サポーター

- 「日常では経験できない現場体験」に価値を感じる人
- 都市部の 20〜40 代、副業 / 週末活動の延長で社会的価値を生みたい層

## 提供価値

| ステークホルダー | 得るもの |
|---|---|
| リーダー | 現場で動いてくれる人手 / 新しい交流 / プロジェクトの認知 |
| サポーター | 日常では味わえない体験 / リターン（モノ・コト・体験）/ 新しい繋がり |

## キーメッセージ

- **「あなたの『好き』が、誰かの『助け』になる。」**
- **「『完成品』よりも、共に汗をかいた『時間』を贈りたい。」**
- 公開は無料 / プロジェクト終了まで手数料 0 円
- 現場共創サービス

## 想定 LP 訪問者の心理

- 「金銭ファンディングは何度かやったが、本当に欲しいのは人手」
- 「自分のプロジェクトに共感してくれる仲間が見つかるかな」
- 「応募ってどんな流れ？怪しくない？」

## 競合・参照

- CAMPFIRE（金銭クラウドファンディング、UI トーンの参照元）
- ランサーズ・クラウドワークス（スキルマッチング、ただし金銭ベース）

## デザイントーン（叩き台の方向性）

- 現場感・生活感・リアリティ（写真の使い方）
- 暖かみ・人肌感（白背景 + 赤アクセント）
- ガチャガチャしすぎない（プロフェッショナルさ）
- 和風すぎず、CAMPFIRE / Indeed くらいの親しみやすさ
