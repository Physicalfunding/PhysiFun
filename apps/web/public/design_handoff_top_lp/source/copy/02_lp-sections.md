## 各セクションの設計意図

### 1. ヒーロー
- 訪問者を 3 秒で掴む
- 主役は **キャッチコピー + 背景動画**
- CTA は「プロジェクトをつくってみる」（応募フォーム `/apply` へ）
- 既存実装: `apps/web/src/components/top/HeroSection.tsx`

### 2. 循環図
- 「あなたの得意なこと」⇄「実現したいこと」⇄「リターン」の三角構造
- アイコンで具体例を周囲に配置
- 既存実装: `apps/web/src/components/top/CycleSection.tsx`

### 3. カテゴリ + 事例カード
- カテゴリタブで絞り込み（建築・カフェ・キャンプ・農業・イベント・スポーツ）
- 各事例カードに 写真 / タイトル / リーダー名 / 支援者数 / 支援時間 を表示
- Phase 1 は **モックデータ**（実プロジェクトはまだ無い）
- 既存実装: `apps/web/src/components/top/CategorySection.tsx`

### 4. 料金訴求 + プロジェクトフロー（新規）
- 「公開は無料 / プロジェクト終了まで手数料はかかりません」
- フィジファンは金銭ではなく時間ベースなので、CAMPFIRE の「成功時手数料」を **「成立まで完全無料」** に翻訳
- 4 ステップフロー: 検討 → 実施 → 成立 → 完了
- 視覚: 横長の矢印バー + 各ステップにアイコン

### 5. リーダーの声（新規）
- 既存リーダー（先行プロジェクト）のインタビュー型カード
- 写真 + 引用文 + リーダー名・プロジェクト名
- 1〜3 件をカルーセル or 縦並び
- Phase 1 段階ではモックでもよい（実リーダー登場後に差し替え）

### 6. 理念文
- 「『完成品』よりも、共に汗をかいた『時間』を贈りたい」
- 4 段落の長文。装飾は最小限、読み物として成立させる
- 既存実装: `apps/web/src/components/top/PhilosophySection.tsx`

### 7. FAQ（新規）
- 4 件をデフォルトに（PDF 参照）:
  1. 「フィジファン」は何故無料なんですか？
  2. 「リターン」の内容に条件はありますか？
  3. 「交通費・宿泊費」は負担してくれますか？
  4. 単発のイベントでも掲載可能ですか？
- アコーディオン形式
- 質問はサービスの不安を先回りで解消

### 8. 応募 CTA + フッター（新規）
- 最後にもう一押し: 「あなたのプロジェクトを始めませんか？」+ 大きめ CTA
- フッター 4 列:
  - **カテゴリー**: 建築 / カフェ / キャンプ / 農業 / イベント / スポーツ
  - **起案サポート**: プロジェクトを作る / 資料請求 / 相談する
  - **サービス**: 利用規約 / プライバシーポリシー / 特定商取引法
  - **フィジファンについて**: 運営会社 / お問い合わせ / ニュース
