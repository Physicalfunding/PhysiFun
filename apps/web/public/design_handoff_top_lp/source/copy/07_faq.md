**含める質問（4 件、PDF 参照）**:

1. **Q: 「フィジファン」は何故無料なんですか？**
   A: フィジファンは金銭ではなく時間とスキルでプロジェクトを支援する仕組みのため、運営として手数料を頂く必要がありません。プラットフォーム自体の運営は別途スポンサーシップなどで賄っています。

2. **Q: 「リターン」の内容に条件はありますか？**
   A: 金銭ではなく、モノ・コト・体験を中心としたリターンを推奨しています。法令に違反するもの・誇大表示などは NG ですが、それ以外は自由に設計いただけます。

3. **Q: 「交通費・宿泊費」は負担してくれますか？**
   A: フィジファンとして一律の負担はありません。ただし、リーダー側でサポーターへの便宜（食事提供 / 簡易宿泊 / 交通費補助）を設定することは可能です。

4. **Q: 単発のイベントでも掲載可能ですか？**
   A: はい、可能です。継続プロジェクトはもちろん、単発の体験イベント / ワークショップも掲載できます。

> ※ 上記回答文は仮置き。次回ミーティングで運営確認の上、確定する。
