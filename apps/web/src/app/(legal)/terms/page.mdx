# 利用規約

---

## 第1章 総則

### 第1条（目的）

本規約は、〇〇株式会社（以下「当社」といいます）が提供する「フィジファン」（以下「本サービス」といいます）の利用条件を、本サービスを利用するすべての方との間で定めるものです。

### 第2条（定義）

| 用語         | 意味                                                                                         |
| ------------ | -------------------------------------------------------------------------------------------- |
| 本サービス   | 当社が運営するスキル・時間でプロジェクトを支援するマッチングプラットフォーム「フィジファン」 |
| ユーザー     | 本規約に同意の上、本サービスを利用する個人                                                   |
| 応募者       | リーダー応募を行い、当社の審査を受ける前のユーザー                                           |
| リーダー     | 当社の審査を経てプロジェクトを立ち上げる権限を付与されたユーザー                             |
| サポーター   | スキル・時間を提供して募集に参加するユーザー（初回リリースでは未公開）                       |
| プロジェクト | リーダーが本サービス上で立ち上げる活動                                                       |
| サポート募集 | プロジェクトに紐付くサポーターへの参加募集                                                   |
| リターン     | サポート募集ごとにリーダーが設計する、サポーターへの返礼                                     |
| アカウント   | 本サービスを利用するために必要な利用者識別情報                                               |

### 第3条（規約への同意・契約成立）

1. ユーザーは、本サービスの利用申込にあたり、本規約に同意するものとします。
2. ユーザーが本サービスを利用したことをもって、ユーザーと当社の間で、本規約を契約内容とする利用契約が成立します。
3. 未成年者は、親権者その他の法定代理人の同意を得たうえで本サービスを利用するものとします。

## 第2章 アカウント

### 第4条（利用資格）

1. 本サービスを利用できるのは、満18歳以上の個人とします。
2. 当社は、反社会的勢力に該当する者その他当社が不適切と合理的に判断する者の登録を拒否することができます。
3. 過去に本規約違反等により利用停止・退会処分を受けた者は、当社が再登録を承認しない限り、本サービスを利用することができません。

### 第5条（アカウント登録）

1. 初回リリースにおいては、ユーザーは当社所定のリーダー応募フォームから応募を行い、応募と同時にアカウントが自動的に発行されます。
2. 応募者は、応募完了時に当社から送付されるアクティベーションリンクを24時間以内にクリックし、パスワードを設定する必要があります。
3. アクティベーションを完了しないまま72時間が経過したアカウントは、当社が自動的に削除します。
4. ユーザーは、登録情報に変更が生じた場合、速やかに当社に通知するものとします。

### 第6条（アカウント管理）

1. ユーザーは、自己のメールアドレス・パスワードを自己の責任において管理するものとし、これを第三者に譲渡・貸与・共有してはなりません。
2. アカウントの管理不十分により生じた損害について、当社は責任を負いません。ただし、当社の故意または重大な過失による場合は、この限りではありません。

### 第7条（退会・利用停止）

1. ユーザーは、当社所定の手続によりいつでも退会できます。
2. 当社は、ユーザーが本規約に違反した場合その他当社が必要と合理的に判断した場合、事前の通知なくユーザーの利用を停止し、または退会させることができます。

## 第3章 サービス

### 第8条（サービスの内容）

1. 本サービスは、お金ではなくスキルと時間を支援の単位とするマッチングプラットフォームです。
2. 初回リリース時点での主な提供機能は以下のとおりです。
   - リーダー募集 LP の閲覧
   - リーダー応募フォームの送信
   - リーダー機能（プロジェクトの作成・編集・公開審査の申請）
   - サポート募集の作成（スケジュール設定まで）
3. サポーター登録・サポート申請等の機能は、一般公開時に実装します。

### 第9条（運営の立場）

1. 当社は、本サービス上の場の提供、応募・プロジェクトの審査、コンテンツ品質の維持を行いますが、初回リリース時点ではリーダーとサポーター間の取引は発生しません。
2. 一般公開以降において、当社はリーダーとサポーター間で成立する活動契約の当事者とはならず、両者間の合意・履行に関し当社は責任を負いません。ただし、当社の故意または重大な過失による場合は、この限りではありません。

### 第10条（リーダー応募・審査）

1. リーダーになろうとする者は、当社所定の応募フォームを通じて応募するものとします。
2. 当社は、応募内容を審査し、適切と判断した場合に限り、応募者にリーダーのロールを付与します。
3. 当社は、審査の基準および結果について、説明する義務を負いません。ただし、却下する場合には、当社所定の方法により応募者に通知します。

### 第11条（プロジェクトの作成と公開審査）

1. リーダーは、本サービス上でプロジェクトを作成・編集することができます。
2. リーダーは、プロジェクトを公開するために当社の審査を申請するものとします。
3. 当社は、当社が定める公開基準に基づきプロジェクトを審査し、公開の可否を決定します。
4. 当社は、公開後のプロジェクトについても、本規約違反・公開基準違反等が認められる場合、当該プロジェクトを非公開に戻すことができます。
5. リーダーが同時に保有できるプロジェクトの件数、公開できるプロジェクトの件数は、当社が別途定める運用基準に従います。

### 第12条（サポート募集）

1. 初回リリースにおいて、リーダーは自己のプロジェクトに対しサポート募集を作成し、募集スケジュールを設定することができます。
2. 初回リリース時点ではサポーター登録機能が公開されていないため、サポート募集に対する申請は発生しません。
3. 一般公開時に、サポート申請、リターン、キャンセル、安全管理等に関する詳細条項を本規約に追加します。

### 第13条（利用料金）

1. 初回リリース時点において、本サービスの利用は無料とします。
2. 当社は、将来本サービスの一部または全部を有料化することができ、その場合は本規約および別途定める料金規定に従って料金を変更します。
3. 規約および料金の変更は、第20条（規約の変更）に定める手続によって行います。

## 第4章 コンテンツ・データ

### 第14条（投稿コンテンツ・知的財産権）

1. ユーザーが本サービスに投稿または提供したコンテンツ（文章・画像・動画等。以下「投稿コンテンツ」といいます）の著作権・著作者人格権は、当該コンテンツを創作したユーザーに帰属します。
2. ユーザーは、当社に対し、投稿コンテンツを本サービスの提供・宣伝・改善のために、無償・非独占・サブライセンス可能な形で利用することを許諾します。
3. ユーザーは、投稿コンテンツが第三者の権利を侵害しないことを保証するものとし、第三者との間で紛争が生じた場合は、自己の責任と費用負担において解決するものとします。

### 第15条（個人情報）

ユーザーの個人情報の取扱いについては、当社が別途定める「[プライバシーポリシー](/privacy)」に従います。

## 第5章 禁止・違反

### 第16条（禁止行為）

ユーザーは、本サービスの利用にあたり、以下の行為を行ってはなりません。

1. 法令・公序良俗に違反する行為
2. 他のユーザー・第三者・当社の権利または利益を侵害する行為
3. 虚偽・不正確な情報を登録する行為
4. 複数のアカウントを不正に登録・運用する行為
5. 同一の応募内容を短期間に繰り返し送信する等、運営業務の妨害となる行為
6. 本サービスを商業目的・営業目的で当社の承諾なく利用する行為
7. 本サービス上でのスパム・大量送信・宣伝行為
8. 本サービスのリバースエンジニアリング・スクレイピングその他類似の行為
9. 本サービスを通じてマルウェアその他のコンピュータプログラムを送信する行為
10. その他、当社が本サービスの運営上不適切と合理的に判断する行為

### 第17条（違反時の措置）

1. 当社は、ユーザーが前条の禁止行為その他本規約に違反したと認める場合、事前の通知なく、投稿コンテンツの削除、プロジェクトの非公開化または削除、アカウントの一時停止、退会処分のいずれかまたは複数の措置をとることができます。
2. 前項の措置によりユーザーに損害が生じた場合であっても、当社は責任を負いません。ただし、当社の故意または重大な過失による場合は、この限りではありません。

### 第18条（反社会的勢力の排除）

1. ユーザーは、自らが暴力団、暴力団員、暴力団準構成員、暴力団関係企業、総会屋、社会運動等標榜ゴロまたは特殊知能暴力集団等その他これに準ずる者（以下「反社会的勢力」といいます）に該当しないこと、および反社会的勢力と関係を持たないことを表明・保証します。
2. ユーザーが前項に違反した場合、当社は事前の通知なく利用契約を解除し、損害賠償を請求できるものとします。

## 第6章 一般条項

### 第19条（免責・損害賠償の限度）

1. 当社は、本サービスの提供にあたり、合理的な注意を払って運営しますが、本サービスがユーザーの特定の目的に適合すること、ユーザーが期待する結果を得られること、本サービスが中断・障害なく提供されることを保証しません。
2. 当社がユーザーに対し損害賠償責任を負う場合、その範囲は、ユーザーに現実に発生した直接かつ通常の損害に限られるものとし、特別損害・逸失利益・拡大損害については責任を負いません。ただし、当社の故意または重大な過失による場合は、この限りではありません。

### 第20条（規約の変更）

1. 当社は、民法第548条の4に基づき、変更がユーザーの一般の利益に適合するとき、または変更が利用契約の目的に反せず合理的なものであるときに、本規約を変更することができます。
2. 当社が本規約を変更する場合、変更後の内容、変更の効力発生日を、本サービス内またはユーザー登録のメールアドレスに対し、効力発生日の相当期間前までに通知または周知します。

### 第21条（通知方法）

当社からユーザーへの通知は、本サービス上の掲示、ユーザー登録のメールアドレスへの電子メール送信、その他当社が適切と判断する方法によって行います。

### 第22条（権利義務の譲渡禁止）

1. ユーザーは、本規約上の地位および権利義務を、当社の事前の書面による承諾なく第三者に譲渡・承継させてはなりません。
2. 当社は、本サービスに関する事業を第三者に譲渡する場合、当該事業譲渡に伴い、本規約上の地位、利用契約に基づく権利義務、ユーザー情報等を当該譲渡先に承継させることができるものとし、ユーザーは予めこれに同意するものとします。

### 第23条（分離可能性）

本規約のいずれかの条項またはその一部が法令により無効または執行不能と判断された場合であっても、その他の条項および無効または執行不能と判断された条項の他の部分は、引き続き効力を有するものとします。

### 第24条（準拠法・合意管轄）

1. 本規約の準拠法は日本法とします。
2. 本規約または本サービスに関連して生じた紛争については、訴額に応じて東京簡易裁判所または東京地方裁判所を第一審の専属的合意管轄裁判所とします。
