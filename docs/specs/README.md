# 設計仕様 (Design Specs)

PhysiFun の設計レイヤー（実装の構造意図）をまとめたディレクトリ。

## 目的

- **人間** が「このサービスの設計がどうなっているか」を俯瞰して把握する
- **AI** が実装作業時に、コードを読む前の「地図」として参照する

## 揮発度ポリシー

**正本はコード**。本ディレクトリはその構造意図の地図に位置付ける。
本書とコードが食い違う場合は **コードが正**。

| 揮発度 | 種類 | 更新方針 |
|---|---|---|
| 低 | アーキテクチャ意図 / ドメインモデル / セキュリティ設計 | 機能追加時に手動更新 |
| 中 | 主要フローのシーケンス | 該当フロー変更時に更新 |
| 高 | ER 図 / API 仕様 | 自動生成 or ソースへのリンク主体（手書きしない） |

## 規約

- 図は **Mermaid** を使う（Markdown 内に直接記述、GitHub・VS Code でレンダリング）
- コードへの参照は `path/to/file.ts:line` 形式で書く
- 「本書が正本」と書ける箇所と、「コードが正本」の箇所を明確に区別する

## 改訂方針

- 機能追加で**設計が変わる場合は同 PR で本ディレクトリを更新**する
- 細かい実装ディテール変更は本ディレクトリに反映しない（コードが正本）
- 設計判断（なぜそうしたか）の記録は本ディレクトリ内に集約する
